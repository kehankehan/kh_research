# Photo slots

Add your photographs to this folder using these exact filenames:

- `profile.jpg` — vertical portrait, ideally 4:5
- `climbing.jpg` — climbing or fieldwork image, ideally 3:2 landscape
- `podcast.jpg` — podcast or science-communication image, ideally square
- `cat.jpg` — cat photograph, ideally 3:2 landscape

The website automatically replaces each labelled placeholder when the matching image exists. JPG, JPEG or WebP files work well, but keep the filenames above unless you also update `index.html`.
