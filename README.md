# KE Han Research Website


## Update the content

- Main editable prose: `assets/content.js`
- Page structure: `index.html`
- Printable web CV: `cv.html`
- Colours, typography and layout: `assets/styles.css`
- Mobile navigation and print button: `assets/site.js`

## Add photographs

Put images in `assets/images/` using these exact filenames:

- `profile.jpg` — vertical portrait, ideally 4:5
- `climbing.jpg` — climbing or fieldwork, ideally landscape
- `podcast.jpg` — podcast or science communication, ideally square
- `cat.jpg` — the reserved cat photograph, ideally landscape
