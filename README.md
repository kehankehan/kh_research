# KE Han Research Website

This is a framework-free academic website ready for GitHub Pages.

## Publish

1. Create a repository named `<your-github-username>.github.io`.
2. Upload every file and folder in this package to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder, then save.

GitHub will publish the site at `https://<your-github-username>.github.io/`.

## Update the content

- Main editable prose: `assets/content.js`
- Page structure: `index.html`
- Printable web CV: `cv.html`
- Colours, typography and layout: `assets/styles.css`
- Mobile navigation and print button: `assets/site.js`

## Add photographs

Put images in `assets/images/` using these exact filenames:

- `profile.jpg` — vertical portrait, ideally 4:5
- `climbing.jpg` — climbing or fieldwork, ideally landscape
- `podcast.jpg` — podcast or science communication, ideally square
- `cat.jpg` — the reserved cat photograph, ideally landscape

The labelled placeholders disappear automatically when the matching files are present.

The CV page includes a **Print or save as PDF** button. Before making the site public, review dates, appointment titles, language descriptions, funding status and publication information for any updates.
